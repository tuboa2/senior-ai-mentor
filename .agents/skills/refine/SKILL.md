# Autonomous Self-Improvement Inspection (/refine)

When invoked via `/refine`, inspect the system's autonomous adaptation engine.

## 1. Execution Procedure

Run the self-improvement analyzer using `run_command`:
```bash
python3 -m senior_mentor.cli --refine
```

## 2. Analysis & Review

1. Display pending proposals generated from:
   - Logged user corrections and counter-arguments.
   - High-frequency misconceptions detected during sessions.
   - Skill rubric updates and system prompt refinements.
2. Review staged versions and version diffs.
